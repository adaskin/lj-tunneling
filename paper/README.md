# Paper source: real-time tunneling in light Lennard-Jones clusters (bounds first)

Every number in the text is a `\num{key}` macro defined in `numbers.tex`; the tables `tab_*.tex` and the figures
`figures/*.pdf` are generated from `../data/` and `../config.toml`. Nothing is typed by hand.

Pipeline (everything, from the repo root):  `bash rerun_all.sh --yes` (simulations, tables, then the two scripts below).
After changing only a run or the analysis:

    python -c "from run import *; run_records(); run_protocol_tables(); run_extrapolation(); run_quantum(); run_cosine_check(); run_parameter_choice(); run_mps_tables()"
    cd paper
    python -I scripts/make_numbers.py   # numbers.tex + tab_*.tex; prints 'CLAIM FAILS' for a hand-written claim the data contradict
    python -I scripts/figs.py           # figures/*.pdf
    pdflatex main; bibtex main; pdflatex main; pdflatex main

(`run_paper()` in `run.py` does the analysis calls of the first line except `run_parameter_choice` and `run_mps_tables`, then the scripts.
`make_numbers.py` needs `data/derived/tn_tables.npz` including `step_cost` and `parameter_choice.npz`.)

A point made with another window or spacing than the protocol would be marked with a dagger in the tables and drawn open or dashed in the figures; none is: all runs
of the paper (N = 2-6 at k = 12; N = 2-5 at k = 16, 20) are uniform runs in `../data/runs/` under the convention Theta(x=0) = 1/2.  A value with no run shows as a red `pending` box
(none now).  The previous convention (Theta(x=0) counted as left) is kept in `../previous-data/`; `make_numbers.py` compares the two (macros `th_*`) and checks that the walls are unchanged.
The code of the first version of the project, which supplied points before the uniform runs existed, was removed on 2026-10-09 (git history).


## Report version (October 2026)

The paper is now a research report: `cover.tex` is the one-page cover (abstract, status table, reading guide, AI-usage statement), `sec4b_static.tex` is the new
section on the spectrum of the start (the follow-up analysis: the finding and figures), and `sec7_open.tex` states what is and is not established.
Everything else of the follow-up (method, one combined table of every case `tab_start.tex`, structural checks `tab_levels.tex`, the reflection-symmetry figure) is in **Appendix D**; `../data/followup/README.md` says which data feed which object.
Numbers are kept out of the running text where a table or figure carries them: `tab_measured` (everything measured by N, Section 4), `tab_static` (the start in the eigenbasis, Section 5), `tab_control`, `tab_scen`, `tab_mc` (the number of cosines that describe the signal, Section 6.1) and `tab_scrit` (Section 6.1) are generated by `make_numbers.py`.
The imaginary-time Monte Carlo discussion (`sec3_framework.tex`, Section 3.3) and the caption of Fig. 1 state that imaginary-time Monte Carlo is not excluded. The follow-up figures
(`fig_spectrum`, `fig_dressing`, `fig_parity`, `fig_tilt`, `fig_cosines`, `fig_control`) and the `fu_*` macros are produced from `../data/followup/` by `scripts/followup_data.py`
(read by `make_numbers.py` and `figs.py`); run `make_numbers.py` before `figs.py` (`fig_control` reads `numbers.tex`). `tab_start.tex` (the old doublet and Stage 1 tables combined) and `tab_levels.tex` are generated tables for Appendix D.

## Files

| file | what |
|---|---|
| `main.tex`, `cover.tex`, `sec1_intro.tex` ... `sec7_open.tex`, `sec4b_static.tex`, `appendix.tex` | the text; `cover.tex` is the one-page cover, `sec4b_static.tex` the spectrum of the start (Section 5) |
| `main.bib`, `main.bbl` | bibliography (verified by the author) |
| `numbers.tex` | generated: one `\defnum{key}{value}%source` per number of the text |
| `tab_*.tex` | generated tables |
| `figures/` | generated figures (pdf and png) |
| `scripts/make_numbers.py` | data -> `numbers.tex`, `tab_*.tex`; 43 hand-written claims are checked against the data (prints `CLAIM FAILS`) |
| `scripts/figs.py` | data -> `figures/`; `python -I scripts/figs.py regime` builds one (names: keys of `ALL`) |
| `scripts/followup_data.py` | the readers of `../data/followup/` shared by the two scripts |
| `main.pdf` | the compiled report (`latexmk -pdf main.tex` in this directory; 37 pages) |

Rules: no number typed by hand (add a macro in `make_numbers.py`), no slides in the repository, no invitation to collaborate in the text.
